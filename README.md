# Roasted

Roasted is a Python-based command-line chatbot created by Aryan. It can chat with users, answer basic questions, solve calculations, generate math practice questions, search Google, show multiplication tables, and provide word meanings, synonyms, and antonyms.

The project also includes a simple login/signup system using a CSV file.

## Features

- Command-line chatbot interface
- User login and signup system
- Personalized greeting based on Indian Standard Time
- Basic conversation responses
- Multiplication table generator
- Calculator for simple expressions
- Random math practice questions
- Google search support
- Date and time response
- Dictionary meaning lookup
- Synonym lookup
- Antonym lookup
- Screen clear command
- Custom bot name changing support

## Tech Stack

- Python
- CSV file handling
- PyDictionary
- pytz
- webbrowser
- getpass
